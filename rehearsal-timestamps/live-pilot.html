    How this version works
    
      
      
    • Press Warm-ups are starting when the recording starts. Copied times count from that moment, so they're ready for YouTube without the converter.
      • 
      
    • Each new mark uses the same piece as the mark before it. Change it if the piece changed.
      • 
      
    • For a mark that isn't about a passage (a break, an announcement), tap Just a note. Only your note is copied.
      • 
      
    • Tap S, A, T or B for who's singing. All four comes out as “tutti”.
      • 
      
    • Same bars copies the bars from the mark before, for when a passage is run again.
      • 
      
    • Only the newest mark is open. Tap any older line to change it.
      • 
      
    • Forgot to press the warm-ups button? Type the start time in the box at the end.
      •
